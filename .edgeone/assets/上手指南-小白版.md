# 双选会看板 · 你只需做 4 件事（全程网页/App 点一点，不用敲黑框框）

> 为什么这些要你自己做？因为 GitHub（代码托管）和 EdgeOne（上线平台）都是**用你自己的账号**的，我没法替你注册或登录。除此之外，代码、定时、部署全都不用你管。

---

## 先一句话说清原理
代码已经帮你写好了。推上 GitHub 之后，是 **GitHub 的云端服务器**每天北京时间 08:00 自动跑"检索→重建→上线"。**你电脑关着、不登录，它照样跑。** 你只需要在最开始办 4 件一次性的事。

---

## 第 1 件事：注册一个 GitHub 账号（在网页上）
1. 打开 https://github.com （用浏览器，比如 Safari/Chrome）
2. 点右上角 **Sign up（注册）**
3. 填邮箱 → 设密码 → 起个用户名 → 验证邮箱，和普通网站注册一模一样
4. 注册完**不用建仓库**，第 3 件事会用软件帮你建

> 如果已经有了 GitHub 账号，直接跳到第 2 件事。

---

## 第 2 件事：装一个叫 GitHub Desktop 的软件并登录
这是一个图形界面软件，不用敲命令。
1. 打开 https://desktop.github.com
2. 点 **Download（下载）**，装好并打开
3. 第一次打开会让你 **Sign in（登录）** → 用第 1 件事的账号登录（会跳浏览器确认一下）

---

## 第 3 件事：把我已经准备好的文件夹"发布"到你的 GitHub
这一步最关键，但我已经把文件都整理成"待发布"状态了，你只管点：
1. 打开 GitHub Desktop
2. 顶部菜单 **File（文件） → Add Local Repository（添加本地仓库）**
3. 在弹出的窗口里，点 **Choose…（选择）**，找到这个文件夹：
   `WorkBuddy/2026-09-04-03-06-49/double_choose/cloud-automation`
   （选中这个文件夹，点打开）
4. 它会显示已识别到一个仓库，点 **Add**
5. 左下角"Summary（摘要）"框里随便写点什么，比如 `第一次上传`
6. 点 **Commit to main**（先把文件存进来）
7. 然后点右上角蓝色的 **Publish repository（发布仓库）**
   - Repository name（仓库名）填：`shuangxuan-dashboard`
   - 把 **Keep this code private（保持私有）** 勾上（更安全，不影响使用）
   - 点 **Publish（发布）**
8. 等十几秒，它会在你的 GitHub 账号下建好这个仓库并上传。完成！

---

## 第 4 件事：给自动部署一把"钥匙"（只填 1 个，其余可空）
要让它每天自动上线到 EdgeOne，需要一把令牌（token）：
1. 登录 EdgeOne 控制台（你在 WorkBuddy 里连过的那个，网址通常是 https://console.cloud.tencent.com/edgeone ）
2. 找到 **Pages** 产品 → 进去后找 **设置 / Settings** → 找 **API Token（访问令牌）** → 点 **创建 / Create**，复制生成的那串字符
   （如果界面里找不到，就在控制台右上角搜索框搜 "API Token"）
3. 回到你的 GitHub 仓库网页（github.com 里你刚建的 shuangxuan-dashboard）
4. 点仓库里的 **Settings（设置） → Secrets and variables → Actions**
5. 点 **New repository secret（新建密钥）**
   - Name（名称）填：`EDGEONE_TOKEN`
   - Secret（值）粘贴刚才复制的那串字符
   - 点 **Add secret**
6. 另外两个密钥 `SEARCH_PROVIDER`、`SEARCH_API_KEY` **现在不用管**（留空即可，看板照样每天更新；以后想让反爬的 30 所学校也自动搜，再补）

---

## 第 5 件事（最后一步）：打开自动运行开关
1. 还在你的 GitHub 仓库网页，点上方 **Actions** 标签
2. 如果看到提示 "workflows aren't being run" 之类，点 **Enable（启用）** / **I understand…**
3. 启用后，它会按北京时间 **每天 08:00** 自动跑

---

## 让看板链接永不过期（强烈建议顺手做）
部署上去的链接默认带一段 `?eo_token=...`，约 3 小时后会过期。想一劳永逸：
1. 在 EdgeOne 控制台找到刚部署的项目 **shuangxuan-dashboard**
2. 把项目设为 **公开访问（Public）**
3. 这样你就得到一个**不带 token、永久有效**的地址，比如 `https://shuangxuan-dashboard-xxxx.edgeone.cool`

> 链接地址在：GitHub 仓库 → Actions → 最近一次运行的日志里，或 EdgeOne 控制台的项目页里都能看到。
